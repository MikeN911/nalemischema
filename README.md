# NalemiSchema

NalemiSchema is a light color theme for Visual Studio Code and Antigravity IDE.

## Installation

Install the extension from a VSIX file in either editor:

1. Open the Extensions view.
2. Select **Install from VSIX...**.
3. Choose the NalemiSchema VSIX file.
4. Select **NalemiSchema** from the Color Theme picker.

The extension requires an editor based on VS Code 1.90 or newer.
